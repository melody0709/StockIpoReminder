# 银行图标来源记录

生成日期：2026-11-09

本目录中的 `*.svg` 均为本仓库在开发期生成的程序化本地徽章，不复制银行官方 Logo、字标或第三方图标包。每个文件由稳定银行 ID、银行名称缩写和区分色组成，用于在离线状态下识别下拉选择；不代表本程序获得相关银行授权或与银行连接。

- 来源：程序自有，开发期脚本生成并人工纳入仓库。
- 授权：与仓库源码采用同一项目内使用方式；银行名称仅用于指示用户选择的机构。
- 运行方式：通过 Rust `include_bytes!` 编译进 EXE，不在运行时联网下载、热链或缓存。
- 文件哈希：以 Git 工作区内容为准；发布包校验由 `SHA256SUMS.txt` 覆盖最终 EXE。

未知银行和未来版本产生的未知 ID 使用 `generic.svg` 降级，不影响账户读取、编辑或提醒调度。
