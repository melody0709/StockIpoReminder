# 银行与还款账户图标来源记录

更新日期：2026-11-10（v0.6.2）

本目录中的 `*.svg` 均为本仓库规范化的本地高质量矢量图形资源，在开发期人工校验并纳入仓库，不依赖运行时网络或外部字体。

## 资源清单与设计规范

1. **主流银行标识 (`icbc.svg`, `ccb.svg`, `cmb.svg` 等 21 家)**：
   - 采用标准 `viewBox="0 0 96 96"`，圆角矩形 (`rx="20"`) 现代徽标设计。
   - 底色严格遵循各商业银行官方 VI 标准品牌色（工行红 `#c7000b`、建行蓝 `#003b8e`、农行绿 `#008566`、招行红 `#e60012` 等）。
   - 图标内部采用 100% 纯矢量几何图形（`path` / `circle` / `polygon`），彻底移除对系统特定字体的依赖，在任何 DPI 和脱机环境下均呈现清晰锐利的几何轮廓。
   - 银行标识仅用于方便用户直观识别其选定的开户或贷款机构，不代表本程序获得相关银行官方授权或与银行系统连接。

2. **四类账户语义降级图标**：
   - `kind_credit_card.svg`：信用卡专属极简卡片轮廓与芯片标识，用于未指定银行的信用卡。
   - `kind_mortgage.svg`：房贷专属房屋剪影轮廓，用于未指定银行的住房按揭贷款。
   - `kind_auto_loan.svg`：车贷专属汽车剪影轮廓，用于未指定银行的车辆消费贷款。
   - `kind_credit_loan.svg`：信用贷专属授信票据与金币堆叠剪影，用于未指定银行的个人信用消费贷款。

3. **通用金融机构建筑轮廓 (`bank_building.svg`, `generic.svg`, `other.svg`)**：
   - 经典多立克立柱神殿建筑剪影，用于未指定或未知金融机构的通用兜底。

4. **动态微徽标（Monogram Avatar）**：
   - 用户选择「其他银行」并输入自定义银行名称（如“盛京银行”）时，由 Rust 运行时根据名称字符串哈希与预设色彩空间动态生成纯矢量 SVG 微徽标，实现确定性配色与个性化识别。

## 运行与许可

- **运行方式**：通过 Rust `include_bytes!` 编译直接嵌入单一可执行文件（EXE），运行期完全离线、零外部 IO、零网络下载。
- **发布校验**：以内置哈希及最终 `SHA256SUMS.txt` 与 WiX MSI 为准。
