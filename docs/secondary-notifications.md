# 第二通知通道安全与隐私说明

Stock IPO Reminder 可以把已经到期的本地提醒同步发送到用户自己配置的企业微信、钉钉、飞书或 PushPlus。该能力默认关闭，是桌面提醒的补充通道，不是服务端推送系统，也不会读取券商账户或自动交易。

## 支持的服务商

| 服务商 | 接受的配置 |
| --- | --- |
| 企业微信机器人 | `qyapi.weixin.qq.com/cgi-bin/webhook/send` 的官方 HTTPS Webhook，必须含非空 `key` |
| 钉钉机器人 | `oapi.dingtalk.com/robot/send` 的官方 HTTPS Webhook，必须含非空 `access_token` |
| 飞书机器人 | `open.feishu.cn` 或 `open.larksuite.com` 下 `/open-apis/bot/v2/hook/` 的官方 HTTPS Webhook |
| PushPlus | token；客户端固定发送到 `www.pushplus.plus/send` |

客户端拒绝 HTTP、带用户名或密码的 URL、URL fragment、非官方主机及不匹配的服务商路径。企业自建代理、任意 Webhook 和邮件 SMTP 当前不支持，避免扩大凭据、证书和内容边界。

## 凭据保存

- Webhook URL 中的 key/access token 与 PushPlus token 均视为秘密。
- 明文只在设置保存和发送请求期间存在于当前进程内存。
- 落盘前使用 Windows DPAPI `CryptProtectData`，采用当前用户范围且禁止交互 UI，并附加产品专用 entropy。
- 加密文件位于 `secrets\secondary-notification.dpapi.json`，SQLite 只保存是否启用和服务商枚举。
- 日志、诊断 ZIP、数据库备份、命令行、环境变量和发布清单不包含凭据。
- 加密文件复制到其他 Windows 用户或电脑后不能解密，需要重新配置。
- 普通 MSI 卸载默认保留当前用户数据，也会保留加密凭据；用户可以先点击“清除凭据”，或使用精确确认的数据清理卸载。

## 发送内容

远程消息只包含：

- 产品名称。
- 公开的新股简称与申购代码。
- 提醒类型和本地到期时间。
- 现有提醒中的首行脱敏摘要。
- “逐只登录券商核对、不自动下单”的边界提示。

不会发送数据库、日志、公告正文、原始接口响应、数据目录、Windows 用户名、设备标识、券商账号、持仓、委托状态或第二通道凭据。

## 传输与响应校验

- 仅使用 HTTPS POST JSON。
- HTTP 重定向被完全禁止。
- 总请求超时 15 秒。
- 响应最多读取 64 KiB。
- HTTP 必须为成功状态，同时服务商 JSON 成功代码必须匹配：企业微信/钉钉 `errcode=0`、飞书 `code=0`、PushPlus `code=200`。
- 错误只记录脱敏摘要，不保存响应正文。

## 持久化、重试与配额

- 本地提醒进入投递租约时，为已启用的第二通道建立独立 Outbox 项。
- 远程失败不改变桌面提醒状态，也不会阻止用户在本机看到或确认任务。
- 远程租约为 2 分钟，进程退出后可以恢复。
- 失败后按 1、5、15、30 分钟退避；第 5 次失败后停止自动重试并在设置页显示耗尽数量。
- 自动批次和“发送测试”在真正联网前统一预留请求记录，滚动 1 小时最多 20 个批次；失败和进程中断的预留均计入配额。
- 请求尝试记录保留 30 天且最多 2,000 条；Delivered、Cancelled、Exhausted 项保留 90 天。
- 切换服务商或关闭第二通道时，尚未完成的旧服务商队列项会取消，避免把旧消息发送给新目标。

## 当前未覆盖

- 邮件、短信和自建通用 Webhook。
- 服务端统一推送或多设备同步。
- 服务商账号登录、群机器人创建和远端消息删除。
- 企业代理、自定义 CA、客户端证书或端到端加密。

这些项目仍保留为后续研究，但在建立明确的身份、密钥轮换、代理信任和删除语义前不会隐式扩展当前安全边界。
